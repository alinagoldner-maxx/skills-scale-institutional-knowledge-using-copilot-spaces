# OctoAcme Project Management Docs — Table of Contents

This README summarizes the project management processes used by OctoAcme and provides easy links to all detailed process documents.

## How OctoAcme Manages Projects (Summary)
- **Customer-first:** Deliver value and great experiences
- **Iterative delivery:** Break down work and deliver in increments
- **Clear ownership:** Each project has a Project Manager (PM) and Product Lead
- **Data-informed decisions:** Measure impact and iterate based on evidence
- **Psychological safety:** Encourage feedback and learning
- **Use of core templates/checklists:** Planning, execution, risks, retrospectives
- **Documented communication cadence and escalation paths**
